## Zadanie

Wskaż **1–3 wątki sąsiadujące z tym kursem, których kurs nie tyka**. Wątek ma być
naturalnym krokiem obok, nie pogłębieniem tego, co już jest, i nie tematem z innej bajki.

- Jeśli kurs pokrywa temat szczelnie i nie ma sensownego wątku obok — zwróć pustą listę.
- `title` to tytuł przyszłej lekcji, `brief` to jedno zdanie: co ta lekcja ma wnieść.
- Nie proponuj wątku, który dubluje pojęcia z listy wyżej.

Zwróć wyłącznie blok ```json:

```json
{ "threads": [{ "title": "…", "brief": "…" }] }
```
